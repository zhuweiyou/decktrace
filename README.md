# 斗地主记牌器（decktrace）

斗地主记牌器。打开游戏后，它会自动识别画面中的牌，在桌面上显示一条置顶牌条，
帮你记住还有哪些牌没出。

## 支持的游戏

- [x] JJ斗地主（微信小程序）
- [ ] 欢乐斗地主（计划中）
- [ ] 其他斗地主（待适配）

## 功能

- **自动识别游戏**：打开游戏后启动 decktrace，自动检测当前游戏窗口，不需要手动选择
- **置顶牌条**：固定 15×30 像素牌面，始终显示在当前窗口上方
- **炸弹提示**：某点数 4 张齐全，或大小王都在时，整组牌反色
- **底牌标记**：底牌可见但还没打出时，在牌面底部叠加朱红“底”印章
- **底牌开局门控**：识别到三张底牌后才开始记牌，避免发牌/翻牌动画误扣
- **自动重置**：检测到新一局的手牌变化时自动清空上一局
- **窗口位置记忆**：下次启动回到上次位置
- **本地运行**：不联网、不上传截图

## 安装与使用

### macOS

要求：macOS 12.3 或更高版本。

1. 下载 `decktrace.app`
2. 拖进「应用程序」文件夹
3. 打开 decktrace

如果系统提示“无法验证开发者”，在「系统设置 → 隐私与安全性」里选择“仍要打开”。

首次启动需要授予屏幕录制权限：

1. 打开「系统设置」
2. 进入「隐私与安全性 → 屏幕与系统音频录制」
3. 打开 decktrace 的开关
4. 完全退出 decktrace，再重新打开

### Windows

要求：Windows 10/11。

Windows 版本仍在开发中，暂未发布安装包。发布后：

1. 下载并运行安装包
2. 按安装向导完成安装
3. 首次启动按系统提示授予屏幕捕获/录制权限

### 通用操作

1. 先打开一个受支持的游戏，进入牌局
2. 启动 decktrace
3. 识别到游戏窗口后，牌条会自动出现
4. 牌局结束后可以直接继续下一局，程序会自动重置

默认情况下不需要选择游戏。应用会扫描当前打开的游戏窗口：

- 只开一个支持的游戏：自动进入
- 没开游戏：窗口显示 `Waiting for game window...`，打开游戏后会自动连接
- 同时开了多个游戏窗口：会使用检测到的第一个；建议只保留一个

### 牌条说明

- 牌面按点数从大到小排列
- **反色牌**：该点数已经四张齐，或大小王都在，提示炸弹
- **“底”印章**：这张牌已在底牌区出现，但仍然算在剩余牌里；真正打出后才会消失
- 等待底牌期间显示全部 54 张，不会提前扣牌

### 快捷键

- `R`：清空本局，重新开始记牌

## 常见问题

### 一直显示 Waiting for game window...

- 确认已经打开受支持的游戏，并进入了牌局窗口
- 确认游戏窗口没有被最小化
- 尝试关闭其他游戏/棋牌类窗口，只保留一个
- 如果仍然检测不到，退出 decktrace 后重新打开

### 牌条是空白的

通常是屏幕录制权限没有生效：

1. 确认系统权限设置中 decktrace 的屏幕读取权限已开启（对应路径见上方 macOS / Windows 说明）
2. 完全退出 decktrace
3. 重新打开

如果权限正常但仍然空白，请附上游戏窗口截图和系统版本反馈。

### 识别结果不准

识别依赖当前游戏的界面和牌面素材。以下情况可能影响结果：

- 游戏换了皮肤、字体或主题
- 窗口缩放比例异常
- 游戏窗口被其他窗口遮挡
- 从一局中间启动，之前已经出过的牌无法补回

可以先按 `R` 重置，再重新进入一局。

### 会上传我的屏幕或数据吗？

不会。采集、识别和记牌全部在本机完成，程序不联网。

## 已知限制

- 从一局中间启动时，无法补回启动前已经出过的牌
- 游戏更新界面或更换皮肤后，识别可能失效
- 不支持同时记多个牌局
- 程序会占用一定 CPU 做实时识别
