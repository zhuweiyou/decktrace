# 斗地主记牌器（decktrace）

自动识别斗地主牌面，在屏幕顶部显示一条**置顶牌条**，帮你记住还有哪些牌没出。

全程在本机运行，不联网、不上传截图。

## 支持的游戏

**电脑端**

- [x] JJ斗地主
- [x] 欢乐斗地主

**手机端（Android）**

- [x] 欢乐斗地主（小程序，横屏）
- [x] 王者斗地主（王者荣耀内，横屏）

其他斗地主待适配。

## 功能

- **自动识别**：电脑端自动检测游戏窗口；手机端点选要玩的游戏
- **置顶牌条**：15×30 牌面，始终显示在游戏画面之上
- **炸弹提示**：某点数 4 张齐全、或大小王都在时，整组反色
- **底牌标记**：底牌可见但还没打出时，牌面底部叠加朱红“底”印章
- **底牌开局门控**：认到三张底牌后才开始记牌，避免发牌/翻牌动画误扣
- **自动重置**：检测到新一局自动清空上一局
- **窗口位置记忆**：下次启动回到上次位置
- **本地运行**：不联网、不上传截图

## 安装与使用

### macOS

要求：macOS 12.3 或更高版本。

1. 打开 `斗地主记牌器.app`
2. 如提示“无法验证开发者”，在「系统设置 → 隐私与安全性」里选择“仍要打开”
3. 首次启动授予**屏幕录制权限**：「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」勾选本程序，然后完全退出、重新打开

### Windows（实验版）

要求：Windows 10/11。**暂未提供安装包**，需要自行从源码构建。

- Windows **不需要** macOS 那种“屏幕录制权限”。
- 请保持游戏窗口**可见、不要最小化**。
- 如果游戏以**管理员权限**运行，本程序也要用管理员权限运行，否则抓不到画面。
- 部分**硬件加速 / 全屏独占**的游戏窗口可能抓成黑屏，这是实验版限制。

### Android（手机 APK）

1. 安装 APK 并打开
2. 第一组：点「授权悬浮窗」，允许悬浮窗
3. 第二组：点要玩的游戏（「小程序欢乐斗地主」/「王者斗地主」），允许屏幕采集
4. 游戏横屏时，顶部会出现牌条；点「停止」结束采集

> 手机端支持「王者荣耀·王者斗地主」与「欢乐斗地主小程序」。注意：部分系统（如 ColorOS）
> 会屏蔽微信小程序画面导致采集成黑屏；「王者斗地主」在独立 App 内录屏正常。

## 电脑端通用操作

1. 先打开一个受支持的游戏，进入牌局
2. 启动「斗地主记牌器」
3. 检测到游戏窗口后，牌条自动出现

默认不需要选择游戏，程序会扫描当前打开的游戏窗口：

- 只开一个支持的游戏：自动进入
- 没开游戏：显示 `Waiting for game window...`，打开游戏后自动连接
- 同时开多个：使用检测到的第一个，建议只保留一个

## 牌条说明

- 牌面按点数从大到小排列
- **反色牌**：该点数已四张齐，或大小王都在，提示炸弹
- **“底”印章**：这张牌已在底牌区出现，但仍算在剩余牌里；真正打出后才消失
- 等待底牌期间显示全部 54 张，不会提前扣牌

## 快捷键

- `R`：清空本局，重新开始记牌

## 常见问题

### 一直显示 Waiting for game window...

- 确认已打开受支持的游戏并进入牌局窗口
- 确认游戏窗口没有被最小化
- 尽量只保留一个游戏窗口
- 仍然检测不到时，退出程序后重新打开

### 牌条是空白 / 抓不到画面

- macOS：确认「屏幕录制权限」已开启，然后完全退出并重新打开
- Windows：无需录屏权限；请确认游戏窗口可见、非最小化，必要时以管理员身份运行本程序
- 手机端：确认已授予悬浮窗与屏幕采集权限
- 硬件加速/全屏独占的游戏可能抓成黑屏，可尝试切换为窗口模式

### 识别结果不准

识别依赖当前游戏的界面和牌面素材，以下情况可能影响结果：

- 游戏换了皮肤、字体或主题
- 窗口缩放比例异常
- 从一局中间启动，之前出过的牌无法补回

可以先按 `R` 重置，再重新进入一局。

### 手机端画面是黑的（微信）

部分系统（如 ColorOS）出于隐私保护会屏蔽微信的画面，此时只能采到黑屏。属系统限制，非识别故障。

### 更新应用后又要重新授权屏幕录制？（仅 macOS）

macOS 的屏幕录制权限绑定在应用签名上，更新后签名变化会需要重新授权，属系统行为。

### 会上传我的屏幕或数据吗？

不会。采集、识别、记牌全部在本机完成，程序不联网。

## 已知限制

- 从一局中间启动时，无法补回启动前已经出过的牌
- 游戏更新界面或更换皮肤后，识别可能失效
- 不支持同时记多个牌局
- 程序会占用一定 CPU 做实时识别
- Windows 为实验版，硬件加速/全屏独占窗口可能黑屏
- Android：ColorOS 等系统可能屏蔽微信小程序画面；王者斗地主在独立 App 内录屏正常
- 王者斗地主：农民一次出很多牌、牌分两排显示时，少数牌可能漏识（持续改进中）
